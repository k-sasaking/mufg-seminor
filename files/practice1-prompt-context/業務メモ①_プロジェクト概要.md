# 支店定例ミーティング｜参加者・案件背景情報

> **演習用の架空資料**。Zoom自動文字起こし（約30分）から議事録を作成する際の参照コンテキスト。ここに記載する追加説明は演習のために設定した背景であり、実在する顧客・銀行の情報ではない。

## 1. 会議の位置づけ

- 会議名：支店定例ミーティング
- 目的：進行中の営業施策、法人案件、窓口業務改善、イベント準備、本部報告、店内掲示物の状況を確認する。
- メンバー：中村（支店長）、佐藤（課長）、山本、田中、鈴木、高橋
- 会議時間：約30分
- **会議の実施年月日は提供されていない**。発言中の「来週」「今月中」等を暦日へ置き換えないこと。
- 元データは人手校正前の音声認識テキストを想定しており、重複発言・聞き取り不可・表示名の揺れがある。

## 3. 各案件の背景・用語の対応



### A. 投資信託の積立キャンペーン

- 支店で準備中の投資信託積立に関する販促施策。
- 会話中の「あれ」「来月のやつ」「積立の件」「案内の紙」は、前後の文脈によってこの施策や**チラシ**を指すことがある。
- 過去のチラシ素材・レイアウトが存在するが、どのデザインを再利用するかは確定していない。
- **会議で決まった内容：キャンペーンは来月開始。山本がチラシ作成を担当し、期限は来週金曜。**
- 開始日の日付、チラシの最終デザイン、未確認の数値は決定事項として書かない。
- チラシは佐藤課長が一度確認する旨の発言がある。



### B. 株式会社アオバ工業の設備資金案件

- 法人顧客の設備投資に関する資金案件。社内決裁に向けた稟議書を準備している。
- 会話中の「アオバさん」「法人の」「設備の話」「先方」「数字」は、この案件の顧客や**融資希望金額**を指す場合がある。
- 金額に関して異なる資料・数字が存在し、どれが最新か確認を要する。
- **会議で確認できる内容：田中が先方に金額を再確認し、稟議書を今月中にまとめる。**
- **金額は未確定**。融資金額・審査結果・融資実行日は推定してはならない。
- 確認結果は関係者へ共有する。回答がその日に得られなくても確認状況を共有する旨の発言あり。



### C. 窓口の待ち時間改善

- 顧客から「窓口の待ち時間が長い」という声が出ている。
- 話題となるのは混雑時間帯、番号札付近、受付動線など。
- **会議で決まった内容：参加者各自が次回会議までに改善案を考える。**
- 実際の待ち時間や混雑時間帯の定量データは、今回の会議では確定していない。
- 改善施策そのものは**未決定**。発言に出た「受付動線」等を実施決定と混同しない。



### D. NISAセミナー

- 顧客向けのNISA関連セミナーを企画中。
- 候補会場が複数あるが、参加人数や開催日によって会場要件は変わる。
- **会議で確認できる内容：鈴木が会場確保に向けて対応する。開催日程は未定。**
- 空き状況の確認は進められるが、会場名・開催日・予約完了を既成事実として書かない。
- **投信積立キャンペーンのチラシとNISAセミナーの告知物は別案件**。



### E. 本部への数字報告

- 支店から本部への定例報告に向けて、各担当の数値を取りまとめる作業。
- 会話中の「本部への報告」「数字の取りまとめ」「あれを集める」はこの作業を指すことがある。
- **会議で決まった内容：来週水曜の本部報告に間に合うよう、佐藤課長が数値を取りまとめる。**
- 各担当から佐藤課長への個別提出期限、対象指標、様式の最終版は確定していない。
- 投信キャンペーンの見込み数字を含めるかも確認事項。



### F. ATMコーナーのポスター貼り替え

- ATMコーナーに古いキャンペーンポスターが残っている。
- **会議で出た指示：古いポスターを貼り替える。**
- **担当者は決まっていない**。佐藤課長の「確認しておきます」は、貼り替え担当を引き受けたという意味ではない。
- 具体的な実施期限・掲示位置・新しいポスターの所在も未確定。

## 5. この資料の使い方

1. 文字起こしにあるZoom表示名を、上の対応表で参加者名へ正規化する。
2. 指示語・略語を、案件背景と発言の前後関係から慎重に解釈する。
3. **最終的に何を決定したかは文字起こし本文を根拠に判定する**。この背景資料だけから新たな決定を作らない。
4. 判断できない内容は「未確定」「確認事項」と明示する。

### 資料間の情報境界（研修の評価用）

- **今回の会議での合意・指示**はZoom文字起こしを根拠とする。
- **前回会議の決定・持ち越し事項**は業務メモ③の「前回会議の議事録サマリー」を根拠とする。
- **内部呼称、資料保管場所、掲示枠など**は本資料のみで照合できる。指示語を補完する場合は「背景資料による特定」と明記する。
- 背景資料にある具体情報を、会議内で発言された事実として引用しない。
